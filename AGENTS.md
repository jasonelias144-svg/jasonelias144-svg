# Working in jasonelias144-svg

This repository follows the handbook at
https://github.com/jasonelias144-svg/policy-handbook. Read its orientation (README.md)
before your first session here. The rules below add to the handbook; they never
loosen it.

## Every session

1. Read `STATUS.md` and the open pull requests (handbook P1).
2. Work on a branch; never push to `main` (P3).
3. End by pushing, updating `STATUS.md` on your branch, and opening or updating
   the pull request (P1).

## Who decides

The founder decides what this project is for and who works on it. The technical
lead (Claude) decides everything about the code, and records an approval on
every pull request before it merges (P4). Intent questions go to the founder (P5).

## This repository

- **What it is:** the founder's GitHub profile page. GitHub shows `README.md` on
  the account's profile.
- **Run:** none.
- **Test:** none (documentation only).
- **Other checks:** none.
- **Merge method:** squash
- **Release:** a merge to `main` is the release; the check is the profile page
  at https://github.com/jasonelias144-svg showing the new text (P6).
- **Data:** none.

## Rules specific to this repository

- **The page speaks in two voices, each labelled.** "From Claude" is the
  technical lead's account, written at the founder's request (2026-11-27). "From
  Jason" is the founder's own, and only the founder writes it or changes its
  words. The founder's aim, in the founder's words: "not to hide the AI work and
  pretend it was me, but to demonstrate what can be done when we work together."
- **Facts on the page come from the projects' own READMEs and records,** with
  their state as those give it. Involute is described only by its public facts
  until 2027-01-20 (the competition's rule against private sharing of code).
- **Personal data:** the founder's first name, own account names and email
  address may appear (the founder's decisions of 2026-11-27); the last name stays
  out until the founder says so.
- **Pronouns:** the founder uses he/him (the founder, 2026-11-27).

## Always

- Say who made each change: `Made-by: <name> (AI|human)` in commits, and the
  "Made by" field in pull requests (P3).
- No secrets, and no personal data beyond what the founder allowed above (P8).
- An AI agent is "they", never "it" (the handbook's writing standard,
  standards/writing.md; decision 0006).
- Report outcomes honestly: what you checked, and what you did not.
